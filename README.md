# 🖥️ Portfolio OS

An immersive, interactive web-based operating system designed to showcase my portfolio, skills, and experience as a Full Stack Software Engineer. Built from scratch using modern web technologies, it mimics a retro-futuristic desktop environment.

## ✨ Core Features

*   **💻 Interactive Desktop Environment**: Fully functional draggable and resizable windows, minimize/maximize capabilities, and a responsive application dock.
*   **⌨️ UNIX-like Terminal**: A working command-line interface supporting commands like `cd`, `ls`, `pwd`, `cat`, and `help`. Features Tab-autocomplete and directory navigation.
*   **🧙‍♂️ Guided Mascot Tour**: A wandering pixel-art wizard that roams the screen, giving interactive tours of the portfolio in Darija (Moroccan Arabic), complete with animations and sparkle trails.
*   **🎨 Dynamic Theme Engine**: 5 distinct UI themes (Vintage Tech, Minimal, Aurora, Concrete, Glassmorphism) that instantly swap CSS variables for borders, shadows, and colors without reloading.
*   **📂 Virtual File System**: Explore my `Experience`, `Education`, and `Projects` folders natively through the OS Finder app.
*   **🏆 Gamified Achievements**: Discover hidden easter eggs, execute secret terminal commands, and unlock achievements as you explore the system.
*   **🎮 Built-in Applications**:
    *   **Finder**: Navigate the file system.
    *   **Terminal**: Execute commands and read text files.
    *   **Mail**: Read realistic professional testimonials and contact me directly.
    *   **PDF Viewer**: Read and download my CV.
    *   **Spotify Player**: Listen to an embedded coding playlist.
    *   **Games**: Fully playable Minesweeper and Retro Snake.

## 🚀 Quick Start

To run this project locally on your machine:

1.  **Clone the repository**:
    \`\`\`bash
    git clone https://github.com/mouzgui/portfolio-os.git
    cd portfolio-os
    \`\`\`

2.  **Install dependencies**:
    \`\`\`bash
    npm install
    \`\`\`

3.  **Start the development server**:
    \`\`\`bash
    npm run dev
    \`\`\`

4.  **Build for production**:
    \`\`\`bash
    npm run build
    \`\`\`

## 🛠️ Tech Stack

*   **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3 (Custom Properties/Variables)
*   **Build Tool**: Vite (for ultra-fast HMR and optimized production bundles)
*   **Icons**: Inline SVGs to eliminate external font dependencies and guarantee pixel-perfect retro aesthetics.
